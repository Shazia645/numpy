# NumPy Basics

A collection of beginner-friendly Python files for practicing **NumPy**, written while learning the fundamentals of data science and machine learning.

## Topics Covered

- Creating NumPy arrays
- Inserting values into arrays (`np.insert`)
- Deleting values from arrays (`np.delete`)
- Joining arrays (`np.concatenate`)
- Splitting arrays (`np.split`)
- and more basic array operations

## Files

| File | Description |
|---|---|
| `numpy_01.py` to `numpy_11.py` | Practice files, ordered from basic to slightly advanced |
| `student.json` | Sample JSON file used for practice |

## Requirements

- Python 3.x
- NumPy

## How to Run

```bash
# Install NumPy
pip install numpy

# Run any file
python numpy_01.py
```
